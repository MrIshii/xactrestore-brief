# xactrestore-brief

A static HTML brief summarizing Carl Ishii's UX work across XactRestore at Verisk, focused on enterprise workflow design, lead intake, and product strategy.

## View the brief online

Open the live brief here:

https://mrishii.github.io/xactrestore-brief/

## Project contents

- `index.html` — the full static brief page
- `.github/workflows/pages.yml` — GitHub Pages deployment configuration

## Local preview

You can preview the brief locally by opening `index.html` in a browser, or by serving the folder locally:

```bash
python -m http.server 8000
```

Then open <http://localhost:8000> in your browser.
